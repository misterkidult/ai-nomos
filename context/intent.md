### 兩件要你知道的

1. **同一篇文章重餵不會重複計數。** 一則目擊的 id 由（文件、詞）決定，重送就地覆蓋 —— 契約 §2 規則 6 說一篇文章一個詞只報一次。但 8/29 直灌那 1314 筆的 id 是舊格式 `<job_id>-<index>`，對不上。已附 `scripts/kv-backfill-docterm.py`，**要你在有 `.env` 的機器上跑一次**，那 341 篇之後重餵才會覆蓋而不是長出第二筆

## 九、第三個意圖：第一次來的人，要知道自己能用 WebMCP 做什麼

> Kidult 08-29 追加。前八節談的是「這個作品要成立」，這一節談的是「這個作品要被看懂」。

前面兩個意圖是**字典要長得對**（詞與定義句是主角）與**這扇門要真的存在**（契約 §6 的寫入路徑，8/29 已補上）。第三個意圖不同：它衡量的不是資料或程式，是**一個素昧平生的人打開這一頁之後的三十秒**。

這件事對參賽的份量不低於前兩者。四個評分項裡，Execution 與 Potential Impact 都落在這裡；而 Addy 8/27 審查說最弱的那項「有用」，弱的正是這一段。**評審打開站的時候，他就是第一次來的人。**

### 兩個主要工作流（Kidult 指定）

| | 工作流 | 使用者拿到什麼 |
|---|---|---|
| **一** | 貼上一篇文章，分出**「已經有的字庫」**與**「可能是新的字庫」** | 這篇文章裡，哪些詞字典已經收了、字典的說法跟這篇一不一樣；哪些詞是字典還沒有的 |
| **二** | 這篇文章分析完之後**匯入資料庫**，成為日後可查詢的字庫 | 我剛剛讓字典長大了：進去了幾筆、哪些被擋下與為什麼、以及我現在就能去查我貢獻的那個詞 |

兩者都不是新功能 —— 底層今天都已經在了（工作流一＝`feedDocument` ＋ 本地比對；工作流二＝`submitFindings` → `POST /api/findings` → `GET /api/sightings`）。**缺的是讓人看得懂它在發生。**

### 第三條：讓一般人也覺得有趣

「有趣」不是動畫或配色（Kidult 8/27 已明講不是那個）。判準沿用 `plan-ui-tension.md`：**兩個數字或兩句話擺在一起才有意思，單一數字沒有。**「這個詞被目擊 16 次」不有趣；「16 篇在賣它、7 篇在擔心它」才有趣。

一個一般人不會為了「AI 詞彙表」回訪，但會為了「原來大家講的不是同一個東西」多看兩眼。**有趣是可用性的前提，不是裝飾。**

### 驗收：怎麼知道做到了

不看畫面好不好看，看這五句話一個沒用過的人講不講得出來：

1. 這個站是幹嘛的 —— 一句話，不用捲頁
2. 我現在能做什麼 —— **三種訪客都要有下一步**：有 agent 的、有環境但沒開權限的、完全沒有 agent 的（99% 的訪客是第三種，退化模式不能是死路）
3. 我要對我的 agent 說什麼 —— 不能要他自己憑空想一段話
4. 我剛剛做了什麼 —— 送出之後知道字典長大了多少，被擋下的知道為什麼（**而且知道那不是他的錯，是 agent 沒照抄原文**）
5. 我之後去哪裡查 —— 從「我剛送出」走得到「我貢獻的那個詞」的詞條頁

### 四、影片那句話的但書（要緊）

階段 D 最強的數字：同一個詞的 389 對定義句，字元三連字 Jaccard 中位數 0.034、最大 0.370、**沒有任何一對超過 0.5**。數字為真。

但它證明的是「**沒有任何兩篇用同樣的字去解釋同一個詞**」—— 關於**措辭**的陳述。它**不能**證明「大家講的不是同一個東西」：兩句話用不同的字說同一件事，字元重疊一樣會很低。要講後者得做語意分群，五天內不值得做。

- 可以講：**沒有任何兩位作者用同樣的話解釋同一個詞。**
- 不能講：所以沒有多數說法／大家講的其實不是同一個東西。

前者更具體也更好懂，建議影片用前者。這個數字同時判死了 `plan-ui-tension.md` 的張力 E（分不出多數派），但負結果本身可用。

### 一個要更正的判斷

我 08-29 中午寫進契約的譯文條款主張「譯文表以目擊 `id` 為鍵，不可用原文」。**這個判斷是錯的，已被 15:00 的裁示推翻**，合併後的契約採用相反做法（以原文字串為鍵），理由我原本沒想到：

- **物理隔離**：以 `id` 為鍵的譯文表與 sighting 對齊，很自然就會有人加一欄 `definition_quote_en`；而三條鎖驗的是「引句必須是 context 的逐字子字串」，譯句一定不是，所以鎖分不出那一欄裝的是原文還是譯文。以原文為鍵，這一欄天生不可能存在
- **失效方式**：以原文為鍵，原文一修譯文變孤兒、畫面掉回原文 —— **看得見的降級**。以 `id` 為鍵反而會顯示一句對不上原文的舊譯文 —— 無聲失效。我原本的推理把兩者搞反了

`public/en.json` 因此**沒有違反契約**，它就是契約要的做法。
